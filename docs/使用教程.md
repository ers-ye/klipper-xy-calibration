# 使用教程（中文）

本教程说明如何用 Klipper 已配置的加速度计手弹测量两条 XY 皮带的振动主频，并查看 CSV。测量过程只采集传感器数据，不会移动打印头或修改运动参数。

## 前置条件

- Klipper 与 Moonraker 正常运行，Mainsail 或 Fluidd Console 可执行 G-code。
- 加速度计已在 Klipper 配置并能正常采样。
- 电脑上安装 Node.js 22.4 或更新版本。
- 皮带可安全触及。弹拨时手指、工具和衣物远离打印头、电机风扇及其他运动部件。
- 先阅读[配置教程](配置教程.md)，确认宏已手动合并进现有 `printer.cfg`，采集器传感器配置与实际传感器匹配。

## 测量位置

每次手弹前，先确认打印机已回零且 XY 移动路径畅通，再通过 Mainsail/Fluidd 手动移动控件将喷头放到 **X=150、Y=150 mm**。X、Y 两条皮带都在该位置采集。`BELT_X` 和 `BELT_Y` 会在 Console 提醒此位置，但宏不会自动移动打印机；未回零或路径有障碍时不要移动或开始采集。

## 实时控制台测量

1. 在项目根目录打开 PowerShell，启动采集器：

   ```powershell
   node tools/belt_session.mjs --host=YOUR_PRINTER_HOST --sensor-config=config/accelerometers/lis2dw.json
   ```

   把 `YOUR_PRINTER_HOST` 换成 Moonraker 可访问的主机名或 IP。不要把私人地址提交到公开仓库。

2. 保持 PowerShell 进程运行，打开 Mainsail/Fluidd 的 Console。
3. 确认喷头已在 X=150、Y=150 mm 后输入 `BELT_X`，只弹拨标记为 X 的那条实体皮带一次。观察 Console 中每秒滚动显示的主频。
4. 等振动衰减后输入 `OK` 结束本次测量。采集器会在它运行的电脑上写入 `outputs/belt_x_*.csv` 并回显汇总值。
5. 输入 `BELT_Y`，按相同方式测另一条实体皮带，再输入 `OK`。
6. 结束本地采集器时，在 PowerShell 按 `Ctrl+C`。

如果当前采集尚未完成，再输入另一个 `BELT_X`/`BELT_Y` 会被忽略；先用 `OK` 结束活动测量。不要在测量过程中移动机器或改变传感器安装。

皮带宏命令速查：

```gcode
BELT_X  ; 开始采集标记为 X 的实体皮带
BELT_Y  ; 开始采集标记为 Y 的实体皮带
OK      ; 结束当前采集并保存 CSV
```

`BELT_X`、`BELT_Y` 与 `OK` 只发起/结束本地采集器会话，不执行运动。宏定义见 `config/printer.cfg.belt-frequency-manual-merge.txt`，需手动合并进现有 `printer.cfg`。

## 单次定时采集

如需采集一个固定时长的窗口，可使用：

```powershell
node tools/belt_frequency.mjs --host=YOUR_PRINTER_HOST --sensor-config=config/accelerometers/lis2dw.json --belt=LEFT --seconds=5
node tools/belt_frequency.mjs --host=YOUR_PRINTER_HOST --sensor-config=config/accelerometers/lis2dw.json --belt=RIGHT --seconds=5
```

`--belt` 可用 `X`、`Y`、`LEFT` 或 `RIGHT`；时长为 2–10 秒。这个命令运行在项目电脑上，完成后直接打印结果并将原始样本 CSV 保存到 `outputs/`。它不需要 `BELT_X`、`BELT_Y`、`OK` 宏。

## 查看 CSV 与解释结果

- `belt_session.mjs` 输出文件包含 Klipper 时间戳和 X/Y/Z 加速度列。
- `belt_frequency.mjs` 输出文件名以 `xy_belt_` 开头，格式相同。
- 显示值是加速度计三轴中检测到的最强频谱峰，不是张力单位，也不是 Klipper Input Shaper 共振校准结果。
- 若读数不稳定、很低或与拨动听感不符，重复同一侧测量，检查加速度计固定是否牢靠、传感器是否能感受到皮带振动，并确认手没有碰到传感器或其他部件。
- 不要只凭一次读数调紧/调松皮带。不同手机应用和本工具可能使用不同的采样窗口、主峰选择和平均方法；截图对照仅记录一次样本，不证明精度相等。
- 没有已知皮带自由跨距、线密度和边界条件时，不将 Hz 换算为张力。

## 单 GPIO 对刀仪插件命令

插件安装和主板 GPIO 配置见[配置教程](配置教程.md)。配置完成后，这些命令只记录试验标记或生成报告；`B2K_CAL_START` 不会执行参数中描述的移动：

```gcode
B2K_CAL_START EXPERIMENT_ID=test_x_01 TOOL_ID=T2 AXIS=X DIRECTION=POS DISTANCE=20 SPEED=20 ACCEL=300 TRIAL=1 START_POS=100 END_POS=120 TEMPERATURE=210
B2K_CAL_STOP
B2K_CAL_REPORT
QUERY_BUTTON BUTTON=b2k_probe
```

`DISTANCE` 只能是 20、50 或 100 mm；`AXIS` 为 X/Y/Z，`DIRECTION` 为 POS/NEG。`QUERY_BUTTON` 用于查看唯一机械开关状态。报告只分析重复定位误差；回调坐标为 `host_estimate`，不是 MCU 精确锁存坐标。

## 常见问题

**Console 没有频率滚动值**：确认采集器仍显示已连接；在 Console 重新输入 `BELT_X` 或 `BELT_Y`；确认 Klipper 数据流 API 与所选 profile 一致；检查 Moonraker 主机地址和 7125 WebSocket 可达性。

**显示传感器数据流错误**：参照[配置教程](配置教程.md)检查 profile 的 `method`、传感器对象名和 API 返回结构。FLY 修改版或其他 fork 可能有定制接口。

**如何停止**：在 Console 输入 `OK` 结束一次采集；在本地 PowerShell 输入 `Ctrl+C` 退出采集器。

## 安全边界

本工具只执行数据采集和分析，不运行任何运动命令，不用 `FORCE_MOVE`，也不自动更改 `rotation_distance`、microsteps、加速度、Input Shaper 或其他运动参数。这里的皮带频率测试是静止状态下手动弹拨，不是 XY 共振扫频校准。
